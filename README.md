Реактивный SSE-сервис, который сообщает, когда молоко собирается убежать — никто не любит отмывать плиту :) 
Архитектура построена с прицелом на масштабируемость и fault-tolerance.  
Тестирует подходы к отказоустойчивой доставке уведомлений через Kafka / Redis.  
Служит упражнением в реализации инженерной избыточности ради опыта.  
*****************************************************************************
A reactive SSE service that notifies you when milk is about to boil over — because no one likes cleaning the stove :).  
The architecture is focused on fault tolerance, high scalability, and low latency.  
It explores resilient delivery techniques using Redis and Kafka.  
Originally built as a playful exercise in deliberate overengineering.
